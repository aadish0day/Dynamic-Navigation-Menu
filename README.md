# Dynamic Navigation Menu

A professional landing page template with a dynamic navbar, smooth scrolling, and a modern glassmorphism UI.

## Features

- **Dynamic navbar** — styling changes on scroll with active section tracking
- **Smooth scrolling** — native-feeling navigation to internal sections
- **Fully responsive** — mobile to desktop
- **Glassmorphism** — modern UI with backdrop blur and animations
- **Sections** — Hero, Features, About, Contact, Footer

## Tech Stack

React 18, TypeScript, Vite 5, Tailwind CSS 3, Lucide Icons, Docker

## Quick Start

```bash
npm install
npm run dev

# Docker
docker compose up -d --build
```

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run lint` — lint
- `npm run typecheck` — TypeScript check
